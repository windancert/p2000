Source code for docker image to receive P2000 messages via a radio dongle and publishes them using MQTT

Just some bullet points on the project:
* Source code archive for source code: https://github.com/windancert/p2000/
* Docker image: https://ghcr.io/windancert/p2000
* I am using the following radio dongle: https://www.rtl-sdr.com/rtl-sdr-blog-v3-v4-usb-c-model-released-for-sale/
* The docker image presupposes a network called mqtt to publish on
* More information about the P2000 messages: https://nl.wikipedia.org/wiki/P2000_(netwerk)
